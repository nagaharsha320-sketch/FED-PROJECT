# Event Management System

An interactive frontend project for a college project/review. It provides a simple and user-friendly platform for viewing upcoming events and registering for them.

## Features

- Interactive event management interface
- Navigation between Home, Events, and Registration sections
- Display of upcoming events
- Event details including date, time, and location
- Event selection through Register buttons
- User registration form
- Name, email, and phone number input
- Event selection dropdown
- Form validation using HTML
- Registration confirmation using JavaScript
- Smooth scrolling to the registration section
- Responsive layout for different screen sizes
- Simple and clean user interface

## Technologies Used

- **HTML** – Website structure and content
- **CSS** – Styling, layout, Flexbox, and responsive design
- **JavaScript** – Event selection, form handling, DOM manipulation, and alerts
- **VS Code** – Development and code management
- **Browser DevTools** – Testing and debugging

## Run

No build tools are required.

1. Download or extract the project.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.

For VS Code, the **Live Server** extension can also be used to run the project.

## How It Works

1. The user opens the website and views the home page.
2. The Events section displays available upcoming events.
3. The user clicks **Register** for an event.
4. The selected event is automatically added to the registration form.
5. The user enters their name, email, and phone number.
6. After submitting the form, JavaScript displays a registration confirmation.
7. The form is reset after successful registration.

## Important

This is currently a **frontend demonstration project**. Registration information is not permanently stored in a database.

In a production version, the project can be connected to a backend, database, authentication system, and LocalStorage or cloud services for persistent event and registration management.
