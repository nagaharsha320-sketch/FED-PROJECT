# Event Management System — A Simple and User-Friendly Event Registration Platform

In today’s college environment, different technical, cultural, and sports events are conducted regularly. Managing event information and registrations manually can be time-consuming and difficult.

As part of our frontend project, we developed **Event Management System** — a simple web-based platform designed to display upcoming events and allow users to register for them through an easy-to-use interface.

## Why this project?

An event management system should make it easy for users to:

- View upcoming events
- Check event details such as date, time, and location
- Select an event
- Enter their personal details
- Register for the selected event

Our project provides these features through a simple and user-friendly website.

## Key Features

### 1. Event Display
The website displays upcoming events in separate event cards. Each card provides the event name, date, time, and location.

### 2. Event Selection
Users can click the **Register** button on an event card. The selected event is automatically chosen in the registration form.

### 3. Registration Form
Users can enter their name, email address, phone number, and select the event they want to attend.

### 4. Form Validation
The registration form uses required fields and input types such as email and telephone to ensure that basic information is entered before submission.

### 5. Registration Confirmation
After submitting the form, JavaScript displays a registration-success message containing the user's name and selected event.

### 6. Responsive Interface
The website is designed to work across different screen sizes. Flexbox is used to arrange the event cards and make the layout adaptable.

### 7. Navigation
The navigation bar provides quick access to the Home, Events, and Registration sections of the website.

## Technology

The project was developed using:

- **HTML** – Used to create the structure of the website, including navigation, event cards, forms, and footer.
- **CSS** – Used for styling, layout, colors, spacing, buttons, shadows, and responsive design.
- **JavaScript** – Used for event selection, form submission, DOM manipulation, scrolling, and registration confirmation.
- **VS Code** – Used as the development environment for writing and managing the project files.
- **Browser DevTools** – Used for testing, inspecting elements, checking responsiveness, and debugging.

### LocalStorage – Future Enhancement

LocalStorage can be integrated to store registration and event data in the browser. This would allow information to remain available even after refreshing the page.

## Project Learning

Working on this project helped us understand how a real event-management website can be designed from a user-interface perspective. We gained practical experience with HTML structure, CSS styling, responsive layouts, JavaScript DOM manipulation, form handling, and user interaction.

The project also helped us understand how different frontend technologies work together to create an interactive web application.
